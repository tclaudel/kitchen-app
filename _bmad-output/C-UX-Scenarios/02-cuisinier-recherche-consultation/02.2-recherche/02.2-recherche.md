# 02.2 - Recherche

## Métadonnées

| Propriété | Valeur |
|---|---|
| **Scénario** | Le Cuisinier pragmatique retrouve une recette |
| **Numéro** | 02.2 |
| **Plateforme** | Mobile |

## Vue d'ensemble

**Objectif de la page :** permettre de saisir un mot-clé et d'identifier rapidement la recette recherchée parmi les résultats.

**Contexte d'entrée :** l'utilisateur vient de l'accueil / bibliothèque et a activé le champ de recherche.

**Action de sortie :** sélectionner la recette correspondante pour ouvrir sa consultation.

**Interactions sur la page :** rechercher dans les titres, ingrédients, tags et descriptions ; afficher les résultats de manière lisible et concise.
