# 02.3 - Consultation d'une recette

## Métadonnées

| Propriété | Valeur |
|---|---|
| **Scénario** | Le Cuisinier pragmatique retrouve une recette |
| **Numéro** | 02.3 |
| **Plateforme** | Mobile |

## Vue d'ensemble

**Objectif de la page :** afficher une recette structurée avec ses ingrédients et ses étapes, lisible sur mobile et prête à être utilisée.

**Contexte d'entrée :** l'utilisateur vient de sélectionner une recette dans les résultats de recherche.

**Action de sortie :** consulter les ingrédients et suivre les étapes de préparation. ✓

**Interactions sur la page :** faire défiler le contenu et consulter les différentes sections de la recette sans quitter la page.
