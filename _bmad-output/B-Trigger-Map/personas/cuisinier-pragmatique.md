# Persona : Le Cuisinier pragmatique

## Contexte

Cette personne consulte les recettes dans différents contextes : avant les courses, pour choisir un repas ou directement pendant la préparation. Elle apprécie les expériences simples comme Cookidoo ou Cookomix.

## Usage

Elle recherche une recette puis la consulte principalement sur mobile, avec un besoin de lecture rapide et d'instructions fiables.

## Objectifs

- Utiliser une application simple.
- Retrouver rapidement une recette.
- Suivre des instructions claires.
- Consulter la recette pendant la cuisine.

## Frustrations

- Instructions peu claires ou contradictoires.
- Étapes manquantes lors d'un import.
- Interface trop compliquée.
- Accès lent ou difficile sur mobile.

## Critère de réussite

La recette recherchée est accessible rapidement et peut être suivie sans ambiguïté pendant la préparation.
